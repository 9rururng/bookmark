크롬용 이미지 돋보기

이미지의 세부 내용을 확인할 때 사용하세요.

아래 보이는 버튼을 그대로 북마크바로 드래그하세요.

이미지 돋보기

북마크바가 보이지 않으면 브라우저 메뉴에서 북마크바 표시를 켜세요.

사용법

  1. 크롬 사용할 탭에서 북마크를 클릭합니다.
  2. 이미지 위에 마우스를 올립니다.
  3. Q를 누르고 있는 동안 2배, W는 3배, E는 5배로 확대됩니다.
  4. 청록색 원은 원본 이미지에서 돋보기가 보여 주는 범위를 표시합니다. 확대 배율이 높을수록 원이 작아집니다.
  5. 키에서 손을 떼면 확대가 사라집니다. ESC는 기능을 완전히 종료합니다.

참고

  • 돋보기 지름은 400px입니다.
  • 페이지에 직접 표시된 이미지 요소를 대상으로 합니다. 별도 미리보기나 iframe 내부 이미지는 동작하지 않을 수 있습니다.
  • 적용 가능 툴(테스트 완료): 그루핑툴, 카탈로그툴, 젠데스크 본문 내 이미지, 일반 웹사이트는 환경에 따라 달라집니다.
